# O QUE É O LINUX?

Raramente utilizamos um sistama operacional diretamente. O que usamos são programas , que utilizam recursos como arquivos, internet e memória, ambos providos do sistem operacional.

  
A melhor forma de pensar em um sistam operacional é imaginar um conjunto de vários programas unidos, aguardando serem usados.


Linux é o kernel (núcleo), o componente central, o coração do sistema. Ele é responsável por conectar o sofware ao hardware.

  
Apenas com o kernel (núcleo) não teríamos muitas opções. São necessários programas, configurações, interface gráfica e drivers pra tirar proveito real do sistema operacional.
