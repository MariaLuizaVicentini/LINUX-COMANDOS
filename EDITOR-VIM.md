# VIM

O Vim é um editor simples, porém bastante flexível. 
Em seguida, veremos o básico sobre ele.


- Podemos entrar no editor com o seguinte comando
```
vi
```

- pra sair do editor
```
:q
```

- abrir um novo arquivo 
```
vi meu_arq_vim.txt
```

- comando pra atualizar o vim
```
sudo apt update && sudo apt install vim -y
```

- como entrar no modo inserção  
```
i
```
SAIDA:
```
-- INSERT --
```

- como salvar o arquivo
```
ESC
```
```
:W
```
