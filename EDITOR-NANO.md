# nano

O nano é mais uma alternativa para edição de textos no terminal, e está disponível
em quase todas as distribuições linux, assim como o vim.


nano
- abre o editor

nano nome-arquivo.txt
- abri arquivo com nano

ctrl + G
- apresenta a tela de ajuda

ctrl + O
- salva o arquivo

ctrl + X
- sai do editor

cntrl  + w
- buscar por uma palavra dentro do arquivo
