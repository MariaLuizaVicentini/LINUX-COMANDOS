# 🐧 Meus Estudos de Linux

Anotações, comandos e práticas baseados no livro **"Começando com o Linux: Comandos, Serviços e Administração"**, da Casa do Código.

## 📌 Sobre o Repositório

Este repositório foi criado para consolidar meus estudos sobre **Linux**, desde os conceitos fundamentais do sistema operacional até a utilização do terminal e a administração do sistema.

O conteúdo é organizado em arquivos Markdown (`.md`), com explicações teóricas, comandos e exemplos práticos para facilitar a compreensão e a consulta durante os estudos.

## 🗂️ Estrutura do Repositório

```text
.
├── ARQUIVOS.md             # Manipulação e visualização de arquivos
├── DIRETORIOS.md           # Navegação e gerenciamento de diretórios
├── HELP.md                 # Manuais e comandos de ajuda
├── LINUX.md                # Conceitos gerais e arquitetura do sistema
├── LOCALIZANDO-ARQUIVOS.md # Localização e busca de arquivos
├── PRIMEIROS-COMANDOS.md   # Comandos básicos do Linux
└── SHELL.md                # Variáveis, atalhos e comportamento do Shell
```

## 📚 Conteúdos Estudados

- **Fundamentos do Linux:** conceitos sobre o sistema operacional e seu funcionamento.
- **Primeiros comandos:** comandos essenciais para utilizar o terminal.
- **Arquivos:** leitura, criação, cópia, movimentação e remoção de arquivos.
- **Diretórios:** navegação e gerenciamento da estrutura de diretórios.
- **Ajuda no terminal:** utilização de manuais e recursos de documentação.
- **Localização de arquivos:** comandos e recursos para encontrar arquivos e diretórios.
- **Shell:** variáveis, atalhos e recursos que facilitam a execução de comandos.

## 🎯 Objetivo

Construir uma base sólida em Linux, compreendendo os conceitos e comandos estudados para aplicá-los com mais autonomia no desenvolvimento de software, na utilização do terminal e na automação de tarefas.

Este repositório funciona como um material de consulta pessoal e acompanha minha evolução nos estudos.
