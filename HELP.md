# PEDINDO AJUDA

help nome-comando
- informa detalhes sobre como usar um determinado comando

man ls 
- apresenta os tópicos da doc linux (página principal)

##### Dentro do Man Page

h
- mostra a ajuda do comando man
q
- sair do man
/ 
- procura por um texto na documentação

##### Obtendo a descrição de comandos

whatis [comando]
- descrição breve sobre o comando
